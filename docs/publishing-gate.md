# Publishing gate

- [ ] Clean worktree, separate from live deployments.
- [ ] `.gitignore` exists before `git add`.
- [ ] No credentials, sessions, client data, logs, backups or production routes are tracked.
- [ ] No client name, IP, domain, Telegram ID or real document is tracked.
- [ ] Provenance and distribution terms are recorded for every included skill and template.
- [ ] License decision is documented for intended visibility.
- [ ] `make check` succeeds in a clean checkout.
- [ ] Synthetic demo runs without production access.
- [ ] Secret scanning and branch protection are enabled after GitHub repository creation.
