# Financial triage

1. Confirm period, currency, source, units and requested metric.
2. Show formula, inputs and any rounding.
3. Separate observed data from assumptions and forecast.
4. Reconcile totals where applicable; name any discrepancy.
5. Do not initiate payments, edits or submissions. Flag them for approval.
